# Quickstart

This guide shows how to send your first event to **Lariba Cloud** using the public HTTP ingestion contract.

## 1) Get an API key

Create an API key for the intended Lariba Cloud project or Event Source with the required ingestion scope.

Store the API origin and credential outside source control:

```bash
export LARIBA_API_BASE_URL="https://your-lariba-api.example"
export LARIBA_SOURCE_API_KEY="YOUR_API_KEY"
```

Do not place API keys in browser bundles, committed files, logs, screenshots, or URLs.

## 2) Send your first event

```bash
curl --request POST \
  "${LARIBA_API_BASE_URL}/v1/events/ingest" \
  --header "Content-Type: application/json" \
  --header "X-API-Key: $LARIBA_SOURCE_API_KEY" \
  --data '{
    "event_type": "user.signup",
    "source": "account-service",
    "properties": {
      "plan": "starter"
    }
  }'
```

A successful request returns HTTP `200` with the accepted event information.

## 3) Verify the event

Open the relevant Lariba Cloud project and inspect the Events surface or use the documented Events API.

The accepted event should retain the producer identity and event type supplied by the request.

## SDK note

A public JavaScript/TypeScript SDK repository is available, but it remains a **developer-preview integration surface** until its event-ingestion contract is aligned with the canonical public HTTP ingestion contract.

See [SDKs](/sdks) for the current compatibility boundary.
