## Read-only inspection

From the backend directory:

```text
cd lariba-cloud
.venv/bin/alembic heads
```

`heads` is script-graph metadata and does not migrate the database.

`alembic current` is different: it connects to the configured database to report its applied revision.

## Mutation boundary

Commands such as:

```text
alembic upgrade ...
alembic downgrade ...
alembic stamp ...
```

change database migration state or authority and must only be run against the intended environment under the applicable runbook/authorization.

B2 does not authorize production migration.

## Troubleshooting import context

Some migration modules import backend code such as `src.database.types`. When invoking Alembic's Python `ScriptDirectory` directly, execute from the backend context or ensure the backend root is on `PYTHONPATH`. The normal repository Alembic CLI invocation from the backend directory already provides the expected project context.
