## High-sensitivity handling

Names containing concepts such as `SECRET`, `TOKEN`, `KEY`, `PEPPER`, `DATABASE_URL`, or `REDIS_URL` must be treated as sensitive or connection-bearing inputs unless their owning implementation explicitly defines them otherwise.

`NEXT_PUBLIC_*` variables are browser-visible by design and must never contain server-side secrets.

## Configuration authority

When documentation and implementation disagree, current tracked settings/configuration code and accepted repository evidence control. Do not infer defaults that are not explicitly present in current source.
