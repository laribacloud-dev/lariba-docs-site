# Developer Golden Path

Use this path to move from a clean local checkout to the documented Lariba Cloud workflow surfaces.

## 1. Install dependencies

Follow [Installation](/developer/installation).

## 2. Configure the local environment

Follow [Environment Configuration](/developer/environment-configuration).

Use development-only credentials and services.

## 3. Start PostgreSQL

Follow [PostgreSQL Bootstrap](/developer/postgresql-bootstrap) and confirm that the local database is reachable.

## 4. Inspect migrations

Follow [Alembic Workflow](/developer/alembic-workflow).

Inspect the migration state before applying schema changes.

## 5. Start the backend

From the backend directory, run the API process in the local development environment:

```bash
LARIBA_PROCESS_ROLE=api uvicorn src.main:app --host 0.0.0.0 --port 8000
```

## 6. Authenticate

Continue with [Authentication](/authentication).

Use a development identity and development credentials.

## 7. Create a source

Continue with [Source Creation](/guides/source-creation).

Keep source credentials private and rotate or revoke them when needed.

## 8. Ingest an event

Continue with [Event Ingestion](/guides/event-ingestion).

Verify that the event appears in the intended development project.

## 9. Configure Sentinel

Continue with [Sentinel](/guides/sentinel).

## 10. Inspect delivery and recovery

Continue with [Worker Health and Recovery](/operations/worker-health-and-recovery).

## Troubleshooting

If a step fails, use [Troubleshooting](/developer/troubleshooting) before changing migration state or bypassing a failed check.

This guide is for local development. Production changes require the production deployment and operations procedures for the target environment.
