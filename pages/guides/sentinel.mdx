# Sentinel

Sentinel provides rule-based monitoring for Lariba Cloud events.

It connects event activity with alerting and controlled automation workflows.

## Core flow

1. Define an alert rule for the event condition you want to monitor.
2. Associate the rule with the intended project and destination configuration.
3. Review rule evaluations and resulting alerts.
4. Review delivery state when an alert is sent to an external destination.
5. For controlled automation flows, review the preview, approval, and policy state before execution.

## Alert rules

Keep rule conditions narrow enough to describe the operational signal you want to detect.

Test new rules against development data before relying on them for operational response.

## Destinations

A destination determines where an alert is delivered.

Keep destination credentials private and test delivery before using a destination for important notifications.

## Controlled automation

Automation previews are reviewable objects. Approval and policy checks are part of the controlled workflow and should be evaluated before an action is treated as executable.
